## Purpose

Toronto/GTA 和 Ottawa 都能看到 BAS、facilities、data center、building systems 相关岗位。这个项目把“楼宇系统排查”做成可展示的记录：不是只看 dashboard，而是能解释点位、趋势、报警和维护建议。

## Planned System

| Component | Evidence |
| --- | --- |
| Sensor data | Temperature, humidity, door state, equipment status, simulated current |
| Dashboard | Live values, trend history, alarm panel, equipment run-time |
| Rules | Over-temperature alarm, missing sensor data, maintenance reminder |
| Report | Weekly energy summary and corrective-action note |
| Diagrams | Device list, simple floor plan, network diagram |

## Why It Fits My Path

BAS work sits between electrical knowledge, controls thinking, and practical documentation. It is a strong match for technician co-op roles because it shows I can read signals, observe trends, and convert alarms into maintenance action.

## Completion Criteria

- One live dashboard.
- One realistic fault scenario.
- One maintenance report.
- Screenshots and a 90-second walkthrough video.
