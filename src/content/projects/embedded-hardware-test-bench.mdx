## Goal

This project connects programming practice with technician work: measurement, repeatability, fault isolation, and reporting.

## Test Bench Concept

The test runner connects to a small device under test and verifies basic hardware functions:

- GPIO output state.
- I2C sensor response.
- UART communication.
- ADC reading within expected range.
- Fault condition when a sensor is disconnected.

## Deliverables

| Deliverable | Why it matters |
| --- | --- |
| `pytest` test suite | Shows repeatable test automation |
| CSV/SQLite logs | Shows traceable measurement history |
| HTML report | Shows pass/fail communication |
| Wiring diagram | Shows hardware clarity |
| Fault injection record | Shows troubleshooting thinking |

## Resume Angle

Built an embedded hardware test bench using Python and microcontroller-based devices to automate functional checks, log measurements, identify failures, and generate pass/fail reports.
