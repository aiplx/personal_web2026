## Working Sequence

This page is a private planning note. It keeps the project areas in one place so they do not stay scattered across chats and bookmarks.

## Project Sequence

| Time | Focus | Evidence |
| --- | --- | --- |
| Summer 2026 | PLC / SCADA mini cell | I/O list, HMI, wiring diagram, test plan |
| Fall 2026 | Course-linked controls updates | motor control scenario, troubleshooting notes |
| Winter 2026-2027 | BAS energy dashboard | trend logs, alarm history, maintenance report |
| Early 2027 | Hardware test or power study | measurement report or one-line documentation |

## Weekly Habit

- Update one project note or README section.
- Save screenshots of working states and failed states.
- Write one short troubleshooting note after each meaningful problem.
- Save useful words from job posts and course descriptions.

## Project Note Rule

Every project note should answer four questions:

1. What system did I build or analyze?
2. What tools did I use?
3. What result did I observe?
4. What failure or tradeoff did I document?
